Installation Instructions

To install Tamil voices on Windows:

  1. Go to Settings → Time & Language → Speech
  2. Click "Add voices"
  3. Download Tamil (India), Hindi (India), and Telugu (India)
  4. Restart your browser
  5. Click "Refresh Voice List" button above

Alternative method:

  1. Go to Settings → Apps → Optional features
  2. Click "Add an optional feature"
  3. Search for and install "Tamil Text-to-Speech", "Hindi Text-to-Speech", "Telugu Text-to-Speech"
