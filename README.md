# MedIntel - AI-Powered Medical Assistant

## 🏥 Overview
MedIntel is an advanced AI-powered medical assistant that provides intelligent medical information, multi-language voice support, and comprehensive health analysis capabilities.

## ✨ Features
- 🤖 **AI Medical Assistant**: Get instant answers to medical questions
- 🗣️ **Multi-Language Voice Support**: Tamil, Hindi, Telugu, and English TTS
- 📄 **Medical Report Analysis**: Upload and analyze medical reports
- 🎯 **Symptom Checker**: Interactive symptom analysis
- 📊 **Health Dashboards**: Comprehensive health tracking
- 🔐 **Secure Authentication**: Google OAuth integration

## 🛠️ Technologies Used
- **Backend**: Python Flask
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **AI Integration**: OpenAI GPT, Custom medical knowledge base
- **Voice Features**: Web Speech API, Text-to-Speech
- **Database**: SQLite with SQLAlchemy
- **Authentication**: Google OAuth 2.0

## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/tharanidharane/MedIntel.git
cd MedIntel
```

2. Install dependencies:
```bash
pip install -r requirements-render.txt
```

3. Run the application:
```bash
python app.py
```

4. Open your browser and navigate to `http://localhost:5000`

## 🎤 Voice Features Setup

For Tamil, Hindi, and Telugu voice support:

1. Go to **Windows Settings > Time & Language > Speech**
2. Click **"Add voices"**
3. Download **Tamil (India)**, **Hindi (India)**, and **Telugu (India)** voice packs
4. Restart your browser and refresh the voice list

## 📱 Usage

1. **Medical Assistant**: Ask medical questions and get AI-powered responses
2. **Voice Interaction**: Use voice input and multi-language text-to-speech
3. **Report Analysis**: Upload medical reports for AI analysis
4. **Health Tracking**: Monitor and track health metrics

## 🔧 Configuration

- Update API keys in environment variables
- Configure database settings in `models.py`
- Customize voice settings in `voice-assistant.js`
